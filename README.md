# 教务管理系统

面向学校的成绩与课表管理原型，支持学生、任课老师、班主任和教务四种角色。数据保存在浏览器 LocalStorage，无需后端。

## 功能

- 身份登录、验证码、学生注册、修改密码
- 成绩查询 / 登记 / 编辑 / 复核（含批量复核）
- 成绩申诉（授权码 + 批准后同步改分）
- 课表查看（按周切换）、排课冲突检测
- 考试安排（学生/老师可查看）
- 用户与班级管理
- 通知中心按真实待办生成
